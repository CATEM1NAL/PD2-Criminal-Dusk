# PAYDAY 2: Thievenfall
A complete gameplay overhaul derived from initial changes made for [Criminal Dawn](https://github.com/CATEM1NAL/PD2-Criminal-Dawn),
adapting the gameplay of PAYDAY 2 to be somewhere between PAYDAY: The Heist and pre-skills 2.0 PAYDAY 3.
While initially based on Criminal Dawn, the changes have greatly eclipsed the
[original list of changes](https://github.com/CATEM1NAL/PD2-Criminal-Dawn/wiki/Gameplay#changes-from-vanilla)
and now broadly cover the entire game.

Check the [wiki](https://github.com/CATEM1NAL/PD2-Thievenfall/wiki) for everything that has changed!
